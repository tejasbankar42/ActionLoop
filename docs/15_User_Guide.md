# 15 · User Guide

| Page | What you can do |
|---|---|
| **Landing** (`/`) | Product overview, animated workflow, team. *Launch Dashboard* / *Explore Workflow*. |
| **Dashboard** | KPIs (documents, successful, pending approvals, validation failures, avg processing, success rate), 14-day activity, agent status, approval preview, recent documents and audit events, Quick upload. Auto-refreshes. |
| **Documents** | Drag-and-drop or browse to upload; select a sample (A–G); *Start processing*; watch stages update live; view the original and extracted fields; *Open in Studio*. |
| **Workflow Studio** | Pick a run; the React Flow graph shows each node's status (idle/running/completed/failed/waiting). Click a node for inputs, outputs, explanation, engine and duration. Failed runs can be retried. The MST node shows anchoring progress. |
| **Agent Intelligence** | Side-by-side Extractor (classification, fields, missing/uncertain, original), Validator (counts, duplicate check, checklist) and Planner (actions, priority, department, reasoning, approval reasons). |
| **Approvals** | Queue by priority. See why approval is needed, the evidence and the plan. Edit highlighted fields, add a comment, then Approve / Request correction / Reject. Decision history below. |
| **Audit & Trace** | Search and filter events, table or timeline view, *Verify entire chain*, *Simulate tampering*, CSV export. Click an event for OFF-CHAIN and ON-CHAIN status, tx hash and MSTScan link; queue or sign the anchor with BridgeKey. |
| **MST Blockchain** | Network, contract, total anchored, relayer status; connect BridgeKey, switch to MST Testnet, authorize your wallet (admin), verify any hash via backend and directly via RPC; transactions table with MSTScan links. |
| **Analytics** | Date range filter, completion/failure/approval/intervention rates, extraction accuracy on labelled samples, charts, agent performance, CSV export. |
| **Settings** | Profile, organization, theme, integration status, processing preferences, validation rules (admin can toggle and change severity). |

Seeded history is labelled wherever it appears and excluded from on-chain anchoring.
